# 跟背诵

每天各五分钟：连续跟原声、准确背一小段、出声读经典。第一版是可以实际练习的网页，手机与桌面共用一套界面。

## 本地使用

```sh
npm ci
npm start
```

打开 <http://127.0.0.1:5173>。本地会启动前端和 Cloudflare 的本地模拟服务，生成独立的随机开发密钥，并应用数据库迁移。已有记录不会被清空。退出时按 Ctrl+C。

此地址是电脑本地预览；手机随时使用需完成下文的线上发布。此版本地跟读示例取自用户已有李笑来音频，文件在被 Git 忽略的 `media/`；没有这些本地文件时，先导入自己的音频材料。

## 日常练习

- **跟**：播放后同步跟原声；跟不上可先跟节奏。变速与 A-B 循环用于困难片段，默认连续播放。可设置循环间隔。
- **背**：全文、提示、隐藏；看原文核对后，逐段确认背准，允许不连续，允许撤销。五分钟内能背多少就背多少。
- **诵**：原文、译文和注释；标记续读位置。
- 五分钟只提醒，不停止音频。暂停或切到后台时停表。结束练习后保存，手机与电脑的记录经同步合并。
- 设置中调整字号、行距、主题和复习时长；导出/恢复练习记录。备份不含音频和连接密钥。

## 准备材料

先读 [材料包格式](docs/material-format.md)。材料由用户提供，AI 或脚本加工；应用不自行搜选，不生成正文，不自动发布。

音频或视频裁剪：

```sh
python3 scripts/prepare_audio.py --input /path/to/audio.mp3 \
  --id my-audio --title 我的跟读材料 --author 原作者 \
  --start 0 --duration 300
```

输出 JSON 与 MP3 到 `media/prepared/`。可传 `--srt /path/to/subtitles.srt`；字幕全部标记待校对，不将机器字幕当作核准文本。

已转出的家书 Markdown 可用 `scripts/prepare_letters.py --input /path/to/家书.md` 生成逐封材料包。句子只按标点拆分，完整译文及注释放在第一句，明确说明未逐句对齐。源文件有六处译文标记错误或缺失，准备脚本修复识别边界并在材料注释中说明；正文错字不静默修改。已生成的 164 份本地包均含译文，位于 `media/family-letters/`。

B 站下载属于准备阶段，可由 Agent 使用用户提供的具体链接下载，再将本地视频交给上述脚本。首版不内置爬取或下载服务，未进行 B 站链接实测。

导入时选择 JSON，预览，再附上音频并确认。默认只导入此设备；勾选同步或在材料卡片上选择同步时，才会上传到你配置的服务。上传材料后再同步练习事件。文字材料可直接练，跟读没有逐字字幕也可播放声音。

## 线上发布

参考 [部署步骤](docs/deployment.md)。前端支持 GitHub Pages；Worker、D1、R2 提供进度与受保护材料。线上网站：[跟背诵](https://wutongyu223.github.io/gen-bei-song/)。同步服务已经部署到 Cloudflare，支持进度与文字材料；音频存储 R2 尚未开通，音频仍由各设备导入。

- 用户写入与 Agent 只读密钥独立。
- 更新正文或音频需提高材料版本，不覆盖旧内容。
- 本地事件先保存，再重试同步；同 ID 重试不会重复累计。
- `GET /api/progress` 提供结构化进度；Agent 可用 `scripts/read-progress.mjs` 读取。部署机的只读连接配置保存在被 Git 忽略的 `work/deploy/agent.json`；可运行 `node scripts/read-progress.mjs work/deploy/agent.json`。
