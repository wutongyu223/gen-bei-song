## 体验优化复验

- 实际练过的材料会更新对应模块的当前材料，首页续练和刷新不再回到先前导入的另一份材料。
- 背诵长原段落按小句确认与撤销；保存 Unicode 字符范围和段内位置。原文、材料版本及旧整段确认记录不变。
- 复习命中仍已背准的小句；跳过复习恢复之前的续练位置。直接选择其他小句也会结束复习并保存新选择。
- 播放、计时、隐藏/提示/核对在底部固定工具栏，390×664 的短手机窗口验证了按钮实际可点到；没有横向溢出。
- 完整未对齐译文独立阅读，关闭后保持原文滚动和段落位置；长译文不会把第一句撑成几千像素。
- 新测试覆盖区间合并和局部撤销、旧记录兼容、Unicode 原文保真、复习命中、段内续练、跨设备/只读进度接口和非法范围拒绝。测试仍使用独立数据库。
- 实际家书 081 的手机隐藏模式截图：`work/ux-after/phone-bei.png`。音频与长译文流程也在桌面和手机尺寸测试通过；真机验证仍待完成。

## Claude 审查后的修复

- 同步前读取云端已有材料清单，只有版本已存在的记录进入上传批次；仅本机材料的记录单独保留，材料页提示先同步材料。用本机材料和内置材料混合队列验证：内置记录上传成功，本机材料及记录没有被自动上传；手动同步材料后剩余队列恢复。
- 多标签页收到已确认上传的队列时，采用最新存储队列，仅补本标签独有的新事件，不再把已经确认的 ID 加回来。
- 云端音频首次下载显示进度，成功后尽力缓存进本机 IndexedDB；复验第二次打开不再请求音频接口。空间不足时仍可播放本次音频。
- 只是打开材料预览并返回，不修改当前续练材料、不新增练习记录。
- 首次选段、切换提示或确认时可自动开始计时；显式暂停后仍由用户恢复。复习到时只提醒，保留用户的提示档和位置。
- 工具栏高度由 ResizeObserver 测量；正文底部留白和定位间距随高度变化，练习时收起站点页头。真实家书在 390×664 复习提示模式工具栏实测 196px（移除重复复习操作后），最后一段确认按钮另有测试。
- Claude 原始意见：`work/claude-review/claude-review.md`。其“主动选句未结束复习”是在读取较早代码时提出，这部分在其审查过程中已改好；最终回归已通过。其高度估算未当作实测结论。
