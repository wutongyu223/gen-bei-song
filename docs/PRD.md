# 跟背诵 · 产品需求文档（PRD）

版本：草案 v0.2（2026-10-06）　状态：用户已于 2026-10-06 授权开发；第一版已实现并通过本地测试，云端发布与真机验证待完成

v0.2 相对 v0.1 的变化：按用户 2026-10-06 的最新澄清改写。材料由用户提供，AI 负责加工；手机通过线上网页使用，不依赖 Mac 开机；Whisper 降为后置的附加功能；删除了过时的必须功能和 Spike。旧的架构方案见 ADR-0001，已被替代。

## 一、背景

用户感到入职场后表达能力和思维能力都在变差。方法来自一条小红书视频（《以前的百家讲坛是真教啊》），讲者主张用「跟、背、诵」三个字练口才，每样每天 5 分钟。视频原文见 `~/Documents/Codex/2026-10-02/new-chat/outputs/小红书视频-文字稿.md`。

视频里三样练习的原意如下，本产品以此为准：

- **跟（早晨 5 分钟）**：找讲得流畅、好听入耳的人，他在前面讲，你在后面同步跟着说。能连续跟住一分钟以上，是讲者给的能力目标。跟不住就哼着节奏，不要停。
- **背（白天 5 分钟）**：「是背，不是背下来，就是背。」5 分钟里能背多少背多少，不要求整篇背完，也不是用自己的话复述；但背过的部分要一字不差。
- **诵（睡前 5 分钟）**：出声诵读经典，不要求背。视频将此归于曾国藩给曾纪泽的建议，但该故事的对应家书出处尚未核实，不作为已确认的历史事实。

**本产品不承诺提升幅度。** 视频里「半个月必有改善、一个月必有提升」以及「做过追踪实验」的说法没有给出来源，本产品不引用这些说法，也不对用户的表达能力或思维能力能提升多少、多快作任何承诺。产品只负责让每天的练习容易开始、容易坚持。

## 二、要完成的工作（JTBD）

> 早上、白天、睡前我各有 5 分钟。练什么材料由我自己提供，AI 负责把它处理成能直接练的样子。每天打开就接着上次练，不用再做任何决定，手机上随时能用。这样我能坚持下去，慢慢把表达和思考能力找回来。

设计原则：

- 这个工具最大的敌人是坚持不下去，不是功能不够。每项设计都要回答一个问题：它有没有让开始变得更容易？
- 它是一个平静的练习工具，不是游戏。不做积分、徽章、连续打卡和惩罚，不制造焦虑。

## 三、使用场景

- 手机和 Mac 都通过线上网页使用。每天练习不依赖 Mac 开机。
- 手机离线使用不是目标。网络暂时不通时，练习记录先存在本地，恢复后再同步。
- Mac 只在准备材料时用到，准备工作可以在 Claude 或 Codex 的 Agent 会话里完成。
- Agent 能读到练习进度，用于陪练和复盘；Agent 不能写入或改动进度。

## 四、两个阶段：准备材料与日常练习

### 1. 准备阶段（偶尔做一次，可在 Agent 会话中完成）

- 材料由用户自己提供或寻找，系统不负责发现和推荐。可能的来源有：李笑来课程的本地音频、B 站单田芳评书视频（转成音频）、《曾国藩家书》、用户自选的经典篇目。
- AI 把材料加工成「材料包」：来源、标题、文本、音频、时间戳、稳定 ID、版本号，以及疑字标记。
- 切分句子或段落时，AI 要结合语义和说话的气口来校验。静音检测只能作为辅助，不能直接当结果。
- 用户预览确认后才导入。**不自动上传、不自动发布用户的任何材料。**
- 第一版不强制开发导入后台，用 Agent 会话加脚本完成即可。
- 材料注意事项：
  - 跟读用的逐字稿必须和音频吻合。李笑来课程的「整理稿」经过补全和删减，不是逐字稿，不能直接当跟读字幕；原始转录稿也有错字，作字幕前要校对。口头赘词特别多的段落可以避开，但用不用李笑来的材料由用户决定，不做禁止。
  - 家书文本来自网络整理版（`~/Documents/Codex/2026-10-02/new-chat/outputs/曾国藩家书（原文·注释·译文）.md`），有错字，还有一处篇名插在信件正文中间。疑点用疑字标记标出，不静默修改。

### 2. 练习阶段（每天）

打开网页默认接着上次练。首页只有三个入口：跟、背、诵，各练 5 分钟。

**5 分钟是软目标，不强制掐断。** 时间到了只做温和提示，正在跟读或诵读的那一句、那一段可以说完；用户也可以继续练，或者提前结束。实际练了多久就记多久。

## 五、三个模块的需求

### 跟

- **核心是连续地同步跟原声**：原声在前面连续播放，用户在后面跟着说，跟不上就哼节奏，不停下。
- 逐句播放和 A-B 区间循环，只用来专门练困难的片段，是辅助手段。不能把默认练法变成「听一句、跟一句」。
- 可调播放速度，字幕可选显示，有计时。
- 「连续跟住一分钟」是能力目标，「每天练 5 分钟左右」是练习时长，两者不混为一谈。
- 不强制录音，不打分，也不反复弹出让用户自评的对话框。

### 背

- 三档显示：全文、提示（例如只留每句首字）、隐藏。
- 流程：先读一遍，再切到提示或隐藏档回忆，回忆完点开原文核对。
- 用户自己标记「背准了哪些」。背准的范围可以是不连续的几段，不假定只能从开头连续往后背。
- 「完成了今天的练习」和「掌握了某段内容」分开记录。没背完整篇不算失败。
- 背得准不准，以用户确认为准。以后即使加了语音识别，机器结果也只作参考，不能直接认定。
- 复习的默认做法：先复习上一次新背的那一小段（约 1 分钟），其余时间练新段。这只是可调的默认值，不强制；用户可以跳过复习，也可以改比例。

### 诵

- 以原文为主，译文和注释点开才显示。
- 从上次停下的自然段接着读，不强制每天换一篇新的。
- 读完即可，不要求背，不检查。

## 六、进度记录与同步

- 每次练习追加一条「练习事件」，只追加、不覆盖。事件包含：唯一事件 ID、日期、模块、材料 ID 和版本、实际练习时长、练到的位置；背诵还要记用户确认背准的范围。自评的完成情况和对内容的掌握情况分开记录。
- 同步接口按唯一事件 ID 去重，重试不产生重复记录。当前进度由事件推算；须明确跨设备并行练习、材料版本变化及用户更正背准范围的合并规则，避免覆盖和重复累计。更正以新的事件记录，不删除旧事件。
- 同步失败的事件先存在本地队列，界面显示最近一次成功同步的时间。
- Agent 通过只读方式读取进度。

## 七、界面与体验

- 安静，像一个阅读工具。三个入口，大按钮放在单手够得着的位置。
- 字体、行距、主题、复习比例都给合理的默认值，用户可以调整，不需要事先逐项决定。例如古文默认用适合长读的衬线或楷体类字体，行距放宽。
- 主题默认跟随系统的浅色或深色，并记住用户手动的选择。
- 练习时尽量防止手机自动熄屏。
- 不做积分、徽章、连续打卡、惩罚，也不用动画奖励。

## 八、技术方案（推荐，具体选型待定）

- **推荐**：用 GitHub Pages 托管静态前端，进度同步用 Cloudflare Worker 加 D1 数据库。这是推荐方案，用户尚未选定具体平台和配置。
- **GitHub Pages 和 Releases 的区别**：Pages 用来托管网站本身；Releases 是给某个版本挂可下载的附件。公开仓库的 Pages 站点和 Releases 附件，任何人都能访问。第一版不使用 Releases。
- **材料的访问权限按材料本身的性质处理**：私人课程（例如李笑来付费课程）和有版权的音频默认受保护，必须经过鉴权才能读取，不能放进公开仓库、Pages 或 Releases；用户确认可以公开分享的材料，按实际权限处理。
- 前端代码和公开仓库不得包含访问凭据。登录、凭据保存与失效方式随鉴权方案确定；用户写入权限与 Agent 只读权限分开。
- 音频和受保护材料具体存在哪里、用什么方式鉴权，**待定**。

## 九、功能优先级（MoSCoW）

### Must（第一版）

1. 首页三个入口，打开默认接着上次练；5 分钟软提示，不掐断。
2. 跟：连续播放原声，用户同步跟读；变速、可选字幕、计时；A-B 循环作为练困难片段的辅助。
3. 背：全文、提示、隐藏三档；先读后回忆；用户标记背准范围（可以不连续）；默认先复习约 1 分钟，可跳过、可调。
4. 诵：原文为主、译文按需展开、从上次的自然段续读。
5. 练习事件记录与跨设备同步；本地暂存，显示最近同步时间；Agent 只读。
6. 平静、可调的界面：字体、行距可调，主题跟随系统并记住选择。
7. 材料包格式，以及在 Agent 会话中完成的准备流程（用户确认后导入）。

### Should / Could（后置）

- 语音识别（Whisper）作为可选附加功能，例如辅助核对背诵，结果只作参考。
- 按遗忘规律安排复习（FSRS，候选库 ts-fsrs）。
- 录下自己的跟读，和原声对比。
- 三个时段分别提醒。
- 「写」模块：每天一个问题、200 字、不用 AI，写完可选让 Claude 追问。

### Won't（这一版不做）

- 发音打分、社交分享、积分和连续打卡。
- AI 自己生成练习内容。AI 只加工用户提供的材料。
- 承诺或展示「能力提升了多少」之类的指标。

- 用户已授权开发，可安装项目所需依赖并在本地运行验证；云端部署及网络配置需另行确认。
- 项目位于 `信息流/跟背诵/`，独立 Git 仓库，每个功能一个分支。提交需用户同意。
- 关键选型写 ADR，放 `docs/adr/`。
