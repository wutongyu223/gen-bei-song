# ADR-0002：静态网页、追加事件与受保护材料

日期：2026-10-06　状态：开发实现；云端资源与发布待配置

## 决定

采用 React + TypeScript + Vite 构建静态前端，可部署到 GitHub Pages。Cloudflare Worker 为单用户提供同步接口；D1 保存练习事件与版本化材料元数据；R2 保存经用户确认上传的音频。网页日常练习不调用 Mac。私有材料与凭据不进入静态构建。

首版用两枚独立随机密钥：用户写入密钥和 Agent 只读密钥。仅凭只读密钥无法写入事件、材料或音频；未配置密钥的服务拒绝访问。部署时必须配置实际网页来源白名单。密钥由用户在设备中设置，不写进前端源码；这是一套个人使用方案，不是多人账户系统。

本地开发通过 Vite 代理和被忽略的 `.dev.vars` 连接本地 Worker。这个代理不进入生产构建。D1、R2 的本地数据在 `.wrangler/`，没有上传到 Cloudflare。

## 进度规则

- 事件 UUID 去重。同 ID、相同内容的重试成功；同 ID、不同内容返回冲突。
- 按结束时间、事件 ID 形成稳定顺序；客户端时钟需要正常。所有设备的时长按唯一事件相加。
- 材料 ID + 版本 + 模块隔离进度。更改文本或音频需增加版本号，旧版背准范围不迁移。
- 每个段落可独立确认、撤销；较晚事件对所涉及的段落生效，其他段落保持原状。
- 续读位置采用最后事件的位置，允许主动回到前文；不取历史最远位置。
- 同步失败保留本地待传队列。同步期间新增的事件不会被旧快照覆盖。
- 实际计时只累计开始后的时间，暂停、切到后台时停表；五分钟只提示，不强制停止。

## 材料与音频

材料由用户提供，准备脚本只裁剪本地文件、生成 JSON，不上传。导入先预览；上传是另一个显式选择。相同 ID/版本的内容不可改写。音频通过鉴权接口访问，支持单区间 HTTP Range；客户端获取后以本地 Blob 播放，避免在媒体 URL 中携带 token。首版音频上限 50 MB，宜提前裁成短片段；大型整课流式播放后续优化。

## 验证与边界

单元测试验证事件去重、跨设备确定性合并、离散背准范围、更正、版本隔离、首字提示和 Range 解析；浏览器测试覆盖桌面与手机尺寸的操作、实际 Worker/D1/R2 接口。手机尺寸模拟不代表真实 iOS Safari 已实测；真机循环和熄屏行为仍需验证。

应用内 ASR、FSRS、提醒、录音对比不在首版。
