# UI 与使用流程审查（v0.1.2）

2026-10-06，通过本机 Claude Code 只读审查 v0.1.1 的源码和手机、平板截图。Claude 没有实际操作网页，也没有测试两台真机；以下修复由 Codex 核实并完成。

Claude 的总体判断：首页三个入口已经能在手机的一屏内看全，信息量和安静的视觉风格可以保留。当前更重要的是背诵核对、后台恢复和第二台设备补音频。

## 核实与处理

| 问题                                 | 处理                                                                                                                                         |
| ------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------- |
| 核对一处会露出后续全部原文           | 只露出当前段或当前小句；确认、撤销或换句后收起。用户仍可自行选择任何小句，支持不连续的背准范围。                                             |
| 后台被系统回收时，中途确认范围未保存 | 时长、确认与撤销范围、续练位置保存为本机草稿；后台暂停也会保存。恢复后计时保持暂停，结束时才写一条正式记录，稳定 ID 防止重复。               |
| 第二台设备没有方便的补音频入口       | 材料卡片提供“附上本机音频／更换本机音频”，只写本机音频库，保留材料版本与已有进度。导入同一版本时仅文件名不同也不再报内容冲突。               |
| 断网英文报错且自动同步反复提示       | 网络异常改为中文。后台自动重试保持安静；手动同步失败说明记录已留在本机；同步成功不会清掉无关的导入提示。                                     |
| 无密钥也能勾选同时上传               | 未连接时禁用上传选项并提示先连接。                                                                                                           |
| 练习操作文字过小                     | 关键按钮文字至少 13px，确认按钮与底部控制点按区域至少 48px；辅助说明放大，恢复 `/ 05:00`，到时提醒用强调色。正文留白仍随工具栏实际高度调整。 |
| 播放异常后播放器消失，所谓重试不可用 | 保留播放器，提供真实的重试与重新加载操作；缓存不存在且未连接时，提示去材料页附上本机音频。                                                   |
| 主屏幕应用中不方便输入连接链接       | 设置允许粘贴完整私人连接链接，提取密钥；说明音频需在当前应用中附上。                                                                         |

只试看一份材料并返回，仍不会改首页的当前材料或新增记录。真正练习并产生草稿后，首页会记住该材料。

## 保留与待确认

- 保留五分钟软提醒、按字范围自行确认、可撤销、无打分，以及正文与完整译文分开阅读。
- 没有采用确认后强制跳到下一句：用户可以只练中间某一句，也可以不连续地确认。
- 平板卡片更大、替换导航符号属于审美建议，未因此扩大首页或增加内容。
- iPhone 主屏幕应用与 Safari 的存储是否隔离、OPPO Pad mini 的实际横屏 CSS 宽度与系统返回手势，仍需真机确认；截图和 Chromium 模拟不能证明这些行为。
- 切后台或锁屏会暂停音频和计时；熄屏跟读的需求与系统行为仍待真机验证。
- 线上尚未开通 R2。文字和正式练习记录可同步，音频仍在各设备分别附上；本机草稿不会作为多条记录上传。

自动验收范围和结果见 [验收记录](validation.md)。
